# 押题卷训练

> 本目录用于 2026 高考最后冲刺阶段。目标不是把押题卷机械刷完，而是让新灵把高频题型、已暴露薄弱点和押题卷里的可拿分题真正掌握。
> 接入日期：2026-05-21

## AI 每次使用押题卷的固定流程

1. 先读 `今日任务.md`、`学习进度.md` 和本目录的 `题型掌握表.md`，确认今天该练什么。
2. 只选 3-5 题，不整卷硬刷；文科大题每次 1-2 道即可。
3. 出题前先自己核对答案，确认题目、答案、解析能闭环。
4. 让新灵先独立做，记录首测结果。不能边讲边做。
5. 批改时只讲错因、核心方法和防错句，不展开成新授课。
6. 同题型换 1-2 道题复测。首测错、复测对只能记为“复测过”，不能直接记“稳”。
7. 更新 `题型掌握表.md` 和 `错题追踪.md`，再按 `课后同步规范.md` 更新各科记录。

## 选题优先级

按下面顺序选，不能只挑简单题：

1. 新灵当前薄弱点对应题型：
   - 数学：数列构造、二项式系数、三角判断、解答题步骤分、填空倒推验证
   - 英语：阅读细节题、语法填空、应用文、读后续写、顽固词语境
   - 语文：文言文语境、名句默写、作文审题、语言文字运用
   - 政治：三段式大题、政治主体、经济/哲学材料匹配
   - 历史：时间线、冷战标志、小论文论证
   - 地理：自然地理选择、非选择题逐问回答、区位模板
2. 江西专版和新高考 I 卷优先。
3. 黑白卷用于考前压轴和查漏。
4. 王后雄、载望、考神密卷作为补充，不替代主线。

## 过关标准

| 类型 | 过关标准 |
|------|----------|
| 数学选填 | 同题型连续 2 次首测正确，且能说出防错点 |
| 数学解答题 | 第一问步骤完整；不会第二问也能写公式抢分 |
| 英语阅读/完形 | 必须先说句意或定位依据，不能凭感觉选 |
| 英语语法填空 | 说出考点类型：谓语、非谓语、词性、从句等 |
| 语文文言文 | 解释关键词义，并能放回原句翻译 |
| 语文作文 | 能列五段式提纲，至少写一段完整论证 |
| 政治大题 | 原理/理论 + 方法论/做法 + 材料关键词，三段齐全 |
| 历史大题 | 观点明确，至少 2 个史实论证，时间不乱 |
| 地理大题 | 逐问作答，分点写术语，有利不利都不漏 |

## 记录铁律

- 押题卷训练只认“首测”和“复测”，不要只写“过关”。
- 错题必须写清：题源、错因、对应知识点、复测安排。
- 所有新增顽固错误，要同步进入 `各科易错点速查卡片.md` 或对应科目进度文件。
- 考前最后一周不再追求新增题量，只复盘 `错题追踪.md` 和各科速查卡。
