# 数学防粗心清单

> 每次做题前口述一遍，形成条件反射

---

## 一、审题阶段（必做）

**□ 1. 我读完整道题了吗？**
- 不要看到熟悉的题型就跳读
- 特别注意："不正确的是"/"错误的是"/"除了"（否定词！）

**□ 2. 我圈出关键词了吗？**
- 定义域（x的范围）
- 单位（厘米/米/千米）
- 正负号（±）
- 特殊条件（"至少"/"至多"/"恰好"）

**□ 3. 我画了图/标了数轴吗？**
- 函数题 → 画草图
- 几何题 → 标已知条件
- 不等式 → 画数轴

---

## 二、计算阶段（必做）

**□ 4. 我检查过符号了吗？**
- 移项变号：x - 3 = 5 → x = 5 + 3（不是 x = 5 - 3！）
- 去括号：-(a - b) = -a + b（不是 -a - b！）
- 负数平方：(-3)² = 9（不是 -9！）

**□ 5. 我检查过分式/根式定义域了吗？**
- 分母 ≠ 0
- 根号内 ≥ 0
- 对数真数 > 0

**□ 6. 我代入验证了吗？**
- 解出答案后，花10秒代入原式验证
- 特别是方程、不等式的解

---

## 三、答题阶段（必做）

**□ 7. 我答非所问了吗？**
- 题目问的是"取值范围"，我写的却是"具体值"？
- 题目要求"整数解"，我写的是所有实数解？

**□ 8. 我漏写单位/区间/集合了吗？**
- 物理量带单位
- 区间写成 (a,b) 或 [a,b]
- 解集写成 {x|...}

**□ 9. 我检查过选择题涂卡了吗？**
- 选项A/B/C/D对应题号
- 不要"会做但涂错"

---

## 四、针对新灵的特别提醒

**历史错误 TOP 5：**
1. 符号错误（移项不变号、负号丢失）→ 每步标出符号变化
2. 定义域忘记 → 看到分式/根式/对数先写定义域
3. 答非所问 → 写答案前再看一眼题目问什么
4. 计算失误 → 关键步骤用不同方法验算
5. 漏看条件 → 把条件列在草稿纸左侧，做完打勾

---

## 使用流程

**做题前（30秒）：**
口述"防粗心清单前三项"→ 读题→ 圈关键词→ 画图

**做题中（随时）：**
卡壳时 → 检查是否漏条件
算完后 → 代入验证

**做完后（1分钟）：**
快速扫一眼答案格式 → 单位？区间？正负？
