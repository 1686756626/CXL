# 高考作文五段式模板

> 目标：从43分→47分，不靠天赋，靠结构

---

## 五段式结构总览

```
┌─────────────────────────────┐
│ 第一段：引（引材料+亮观点）   │ 80-100字
│ 第二段：论A（正面论证）       │ 150-200字
│ 第三段：论B（反面/深化论证）   │ 150-200字
│ 第四段：合（辩证/联系现实）    │ 100-150字
│ 第五段：结（重申论点+升华）    │ 80-100字
│ 合计：约600-750字             │
└─────────────────────────────┘
```

---

## 第一段：引（80-100字）

**公式**：概述材料→提炼关键词→亮明论点

**模板**：
```
材料讲述了____的故事/现象。（20字）
在我看来，这背后折射的是____与____的辩证关系。（30字）
因此，我认为____。（20字）
```

**示例**（2023年全国卷"故事的力量"）：
> 材料讲述了一个关于故事如何改变人生的现象。在我看来，这背后折射的是个体成长与文化传承的辩证关系。因此，我认为好的故事不仅能触动心灵，更能凝聚力量、改变命运。

---

## 第二段：论A（150-200字）

**公式**：分论点A + 事例（一句话）+ 分析（为什么支持论点）+ 小结

**模板**：
```
首先，____是____的基石/前提/基础。（分论点，20字）
正如____，他/她____，最终____。（事例，40字）
这正是因为____，所以才____。（分析，40字）
由此可见，____。（小结，20字）
```

**示例**（"坚持"）：
> 首先，坚持是实现理想的基石。正如屠呦呦，她在提取青蒿素的过程中经历了190次失败，但仍然坚持试验，最终成功发现了拯救数百万人生命的药物。这正是因为她坚信科学的力量，所以才在无数次失败后依然选择坚持。由此可见，唯有坚持，才能让量变积累成质变。

---

## 第三段：论B（150-200字）

**公式**：分论点B + 事例 + 分析 + 小结

**类型选择**：
- 反面论证：如果不…会怎样
- 深化论证：从另一个角度看同一个问题
- 对比论证：A和B的对比

**模板（反面论证）**：
```
然而，____并非易事/____也面临挑战。（转折，20字）
反观____，他/她因为____，最终____。（反面事例，40字）
这警示我们____。（分析，40字）
因此，____。（小结，20字）
```

**示例**（"放弃也是智慧"）：
> 然而，一味坚持并非总是正确的选择。反观鲁迅，他原本在日本学医，但当意识到医学只能治愈身体的病痛而无法唤醒国民的灵魂时，他毅然弃医从文。这警示我们当方向错误时，及时调整比盲目坚持更重要。因此，放弃不是懦弱，而是为了更好地出发。

---

## 第四段：合（100-150字）

**公式**：A和B不是对立的，而是… + 联系现实

**模板**：
```
综上所述，____与____不是对立的，而是相辅相成的。（20字）
当____时，我们更需要____；当____时，我们更需要____。（40字）
联系当下，____。（联系现实，40字）
因此，____。（总结，20字）
```

**示例**（"坚持与放弃"）：
> 综上所述，坚持与放弃不是对立的，而是相辅相成的。当方向正确时，我们更需要坚持；当发现方向有误时，我们更需要放弃。联系当下，无论是学业还是人生，我们都需要在坚持中保持清醒，在放弃时保有勇气。因此，真正的智慧在于知道何时该坚持，何时该放弃。

---

## 第五段：结（80-100字）

**公式**：重申论点 + 升华/号召

**模板**：
```
总而言之，____。（重申论点，30字）
愿我们都能____。（升华/号召，30字）
唯有如此，____。（收尾，20字）
```

**示例**：
> 总而言之，坚持与放弃都是人生的必修课。愿我们都能在正确的道路上坚持到底，在错误的岔路口勇敢转身。唯有如此，我们才能在人生的长途中行稳致远，抵达心中的彼岸。

---

## 二元立意公式速查

| 二元词 | A面 | B面 | 合：辩证统一 |
|--------|-----|-----|-------------|
| 快与慢 | 快=效率 | 慢=质量 | 该快时快，该慢时慢 |
| 得与失 | 得=收获 | 失=成长 | 失是另一种得 |
| 坚持与放弃 | 坚持=方向对 | 放弃=方向错 | 知道何时坚持何时放弃 |
| 个人与集体 | 个人=价值 | 集体=力量 | 个人在集体中实现价值 |
| 传统与创新 | 传统=根基 | 创新=发展 | 在传承中创新 |

## 万能素材卡

### 素材1：屠呦呦
- **人物**：屠呦呦，中国药学家，诺贝尔奖得主
- **事件**：经历190次失败后成功提取青蒿素
- **可论证方向**：坚持、科学精神、传统与现代结合

### 素材2：鲁迅
- **人物**：鲁迅，文学家、思想家
- **事件**：弃医从文，用笔唤醒国民
- **可论证方向**：放弃与选择、责任、转型

### 素材3：苏炳添
- **人物**：苏炳添，短跑运动员
- **事件**：32岁跑出9秒83，打破亚洲纪录
- **可论证方向**：突破自我、坚持、年龄不是界限

### 素材4：袁隆平
- **人物**：袁隆平，"杂交水稻之父"
- **事件**：一生致力于杂交水稻研究，解决粮食问题
- **可论证方向**：奉献、坚持、家国情怀

## 作文检查清单

交卷前逐项检查：
- [ ] 五段结构完整
- [ ] 论点在第一段末尾明确亮出
- [ ] 每段有分论点
- [ ] 论证段有"事例+分析"
- [ ] 第四段有"辩证统一"
- [ ] 字数600+
- [ ] 无明显错别字
- [ ] 标点使用规范
