# 赤壁赋名句默写专项

> 高考必背，今年很可能考

---

## 重点句（必须一字不差）

### 1. 写景名句（高频考）
**原句：** 清风徐来，水波不兴。
**翻译：** 清风缓缓吹来，水面没有掀起波浪。
**考点：** "徐"=缓缓，不要写成"斜"

**原句：** 月出于东山之上，徘徊于斗牛之间。
**翻译：** 月亮从东山上升起，在斗宿和牛宿之间徘徊。
**考点：** "斗牛"=星宿名，不是打架的牛

**原句：** 纵一苇之所如，凌万顷之茫然。
**翻译：** 任凭小船漂去，越过那茫茫的江面。
**考点：** "苇"=小船，"凌"=越过

### 2. 议论名句（高频考）
**原句：** 寄蜉蝣于天地，渺沧海之一粟。
**翻译：** 像蜉蝣一样寄生在天地之间，渺小得像大海里的一颗谷粒。
**考点：** "蜉蝣"（fú yóu）=昆虫，"渺"=渺小，"粟"=谷粒

**原句：** 哀吾生之须臾，羡长江之无穷。
**翻译：** 哀叹我生命的短暂，羡慕长江流水的无穷无尽。
**考点：** ⭐ 今年最可能考，"须臾"=短暂，"无穷"=无尽

**原句：** 挟飞仙以遨游，抱明月而长终。
**翻译：** 希望同飞仙一起遨游，抱着明月而永世长存。
**考点：** "挟"=携同，"长终"=永远存在

### 3. 哲理名句（理解性默写）
**原句：** 逝者如斯，而未尝往也；盈虚者如彼，而卒莫消长也。
**翻译：** 流去的江水像这样不断流去，其实并没有真正流去；时圆时缺的月亮像那样不断圆缺，最终并没有增减。
**考点：** 理解性默写常考，表达"变与不变"的哲理

**原句：** 盖将自其变者而观之，则天地曾不能以一瞬；自其不变者而观之，则物与我皆无尽也。
**翻译：** 从事物变化的一面看，天地连一眨眼的功夫都不能保持原样；从事物不变的一面看，万物和我们都是永恒的。
**考点：** 理解性默写，"变与不变"的辩证关系

## 易错字清单（必须手写一遍）

| 字 | 易错写法 | 正确写法 | 记忆 |
|---|---------|---------|------|
| 蜉蝣 | 浮游 | 蜉蝣 | 虫子旁，因为是昆虫 |
| 渺 | 缈 | 渺 | 水旁，因为像沧海 |
| 粟 | 栗 | 粟 | 下面是"米"，因为是谷粒 |
| 须臾 | 虚于 | 须臾 | "须"=片刻，"臾"=短暂 |
| 挟 | 夹 | 挟 | 提手旁，因为是"携同" |
| 徘徊 | 俳徊 | 徘徊 | 双人旁，因为走来走去 |
| 斗牛 | 斗/牛分开 | 斗牛 | 星宿名，连在一起 |
| 盈虚 | 赢虚 | 盈虚 | "盈"=满，"虚"=缺 |

## 测试题（高考真题风格）

### 题1（直接默写）
苏轼《赤壁赋》中描写江面风平浪静的句子是："______，______。"
**答案：** 清风徐来，水波不兴。

### 题2（直接默写）
苏轼《赤壁赋》中感叹人生短暂、自然永恒的句子是："______，______。"
**答案：** 哀吾生之须臾，羡长江之无穷。

### 题3（理解性默写）
苏轼在《赤壁赋》中以"______，______"两句，从变化的角度说明天地万物瞬息万变。
**答案：** 盖将自其变者而观之，则天地曾不能以一瞬。

### 题4（理解性默写）
苏轼在《赤壁赋》中从不变的角度说明万物与我们都是永恒的两句是："______，______。"
**答案：** 自其不变者而观之，则物与我皆无尽也。

### 题5（语境翻译）
"寄蜉蝣于天地，渺沧海之一粟"表达了作者怎样的心情？
**答案：** 感叹个人生命的渺小和短暂，在广阔天地和历史长河面前感到自身的微不足道。
