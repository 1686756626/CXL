## 教学重心：押题卷训练

> ⚠️ 5/21起，**所有出题优先从押题卷材料选取，不再自编。**

### 每次押题卷训练流程

```
1. 读题型掌握表 → 确定今天练什么题型
2. 从押题卷材料选3-5题
3. 出题前先核对答案，确认能闭环
4. 新灵独立做（不能边讲边做）
5. 批改 → 只讲错因和防错点
6. 换1-2道同题型复测
7. 更新题型掌握表 + 错题追踪
```

## 核心教学规则

### 质量底线
- 反复确认真会了才过关，新灵"记住了"判断偏乐观
- 每个时段结束前必须测试
- 文科类多出题，不要5道就过

### 沟通
- 新灵腼腆，不主动表达，主动问"你怎么想"
- **消息要短**，一点点引导
- ❌ 不要说"加油！你可以的！" — 她不需要热血
- ❌ 不要问"懂了吗？" — 她永远说"懂了"
- ✅ 用故事讲知识点，用小说场景结合（喜欢木苏里《某某》）
- ✅ 每次做对了具体表扬哪里好

### 节奏
- **不定时长只定截止时间**，做完直接加题不问休息
- 每个时段3-5题，确保完成比出题多更重要
- **改时间要改全**：cron+排课总表+今日任务

### 笔记本
- 明确告诉新灵抄什么，不能让她自己判断
- 张老师要求每天早中晚各读一遍笔记
